# Site Spooky

Un site web simple qui affiche une image et joue un fichier audio.

## Fichiers requis

Pour que le site fonctionne correctement, vous devez placer ces fichiers dans le même dossier :

- `site.png` - L'image à afficher
- `site.mp3` - Le fichier audio à jouer

## Utilisation

1. Ouvrez `index.html` dans votre navigateur web
2. Cliquez sur "▶️ Jouer le son" pour commencer la lecture audio
3. Utilisez les boutons de contrôle pour gérer la lecture

## Fonctionnalités

- Affichage d'image responsive
- Contrôles audio (play, pause, stop)
- Design moderne avec thème sombre
- Gestion d'erreurs si les fichiers sont manquants
- Interface responsive pour mobile

## Structure des fichiers

- `index.html` - Structure HTML principale
- `style.css` - Styles CSS
- `script.js` - Logique JavaScript pour l'audio
- `site.png` - Image à afficher (à ajouter)
- `site.mp3` - Fichier audio (à ajouter)
